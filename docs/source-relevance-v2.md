# 来源相关性 v2：本地附加原文与语义失败审计

## 本轮结论

短来源可以由程序根据经过校验的来源 ID 附加完整原文，避免让模型重抄引用。但语义判断仍会遗漏条件不同的风险，暂不作为自动过滤器接入正式推荐。权重和默认 RAG 不变。

## 实现

`assess_sources(..., quote_mode='source_text')` 使用不含 quote 的严格输出 schema，验证 ID 完整、无重复、无未知来源及标签组合后，附加 `source_text` 和 `text_origin=local_full_source`。不把全文伪装为模型挑选的支持性摘录；全文真实不意味着判断真实。

输入仍是原始问题和已有主题，不新增用户细节字段。每批最多 4 条、每条 600 字符。保留原有 `model_quote` 模式用于历史复现；正式证据抽取的逐字引用检查未放宽。

审计包装在本地校验之前记录模型原始返回，失败批次也可分析。输出仅为实验合成材料；没有把审计日志接入真实用户请求。评估脚本支持选择单个旧案例诊断，以及选择新冻结语料和引用模式。每轮请求前保存输入、代码 SHA256 和预算。

## 两次运行

1. 旧案例诊断：`evaluation/relevance-result-20261120T225031534501.json`。只运行 day-calls，1 次请求在 45.10 秒超时；峰值 RSS 32.72 MiB。没有返回内容，不能解释此前引用失败的具体原因。没有自动重试。
2. 新材料验证：`evaluation/relevance-result-20261120T232602108784.json`。4 组共 16 条新合成材料，标签在调用前冻结。4 次串行调用，11.62 秒，峰值 RSS 33.30 MiB。前三批通过本地校验，第四批因 evidence/none/none 的不一致组合停止。原始四批返回均已保存。无数据库写入、无服务启动、无默认排序变化。

沙箱内旧诊断超时之后，新材料运行通过受审批的沙箱外命令执行；不能凭此断言旧超时一定由沙箱造成。

运行预算仍为每轮最多 4 次调用（旧案例限定 1 次）、180 秒总时限、256 MiB RSS、单次 45 秒、响应最多 4 MiB。本轮总共发起 5 次请求，没有再次调用模型调整结果。

## 离线检查：含被拒绝批次，不能当作完整管线成绩

独立文件 `evaluation/relevance-v2-audit.json` 保留原报告/语料哈希，未修改冻结报告。复现：`.venv/bin/python scripts/analyze_relevance_v2.py`，无网络调用。

| 检查 | 结果 |
| --- | --- |
| 三个标签全部匹配预置标签 | 11/16 |
| 标为具体证据且保留风险方向 | 5/6 风险材料 |
| 识别仅提及/无关干扰材料 | 6/6 |
| 通过本地输出契约的批次 | 3/4 |

以上是助手编写合成标签上的诊断，不是独立人工评估，也不是线上质量。未宣称门槛通过。关键偏差：

- **周末风险被弱化**：周末聚会吵、没有工作日观察，被标成有证据却无方向、无覆盖。正好暴露“条件不同不等于风险无效”的问题，本地一致性校验成功拦住这一组合。
- **混合方向被压缩**：同一材料 7 点安静、9 点吵，模型仅标 risk；全文仍在，但标签丢失了正面方向。
- **不确定归属的语义不统一**：无法确定属于哪个房源的噪声被标成 uncertain/risk，另一条被标 uncertain/none/none。不能把这些标签直接计入房源事实或评分。
- **覆盖标签存在定义歧义**：2–4 点要求全程安静，3 点吵醒的反例无需覆盖两小时就能反驳要求。模型标 specific，预置标签为 partial。原标签不改；后续应将“观察范围完整性”和“是否直接违反需求”区分，不能用单个 coverage 标签同时表示两者。

## 验证与后续收敛

83 项回归测试通过，含数据库测试；无真实模型调用，峰值 RSS 53.03 MiB。新增验证本地全文不会丢掉正反两句、乱序来源仍正确绑定、未知来源拒绝、模型不能注入本地来源字段、schema 相互独立、不一致证据被拒绝、输入长度受限。

下一步先定义更小且不混义的标注规则并做人工可读的案例审核，不继续拿这 16 条调提示词并称其为新测试集。来源归属不确定应进入待核实，部分风险仍保留；明确覆盖不能等同于跨时间有效或真实可靠。之后再用新冻结材料验证，才考虑增加影子诊断（仅展示、不参与删除或排序）。

面试叙事：我们先消除了引用抄写的机械错误，再发现来源相关性、风险方向和条件覆盖是不同问题。完整审计使失败可定位，而不是以一项“准确率”掩盖不同错误。没有为展示而把未通过验证的过滤器放入主链路。
