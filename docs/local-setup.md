# 本地体验与模型配置

本地手动比较已经可以使用；只有自然语言解析和 AI 证据解释需要 API 配置。模型配置由用户在自己的终端输入，密钥不用发到聊天，也不用写入仓库。

## 立即体验

```sh
cd choice-match
.venv/bin/python local_db.py start
python3 server.py
```

打开 http://127.0.0.1:8767 。页面支持虚构案例、历史广告、预算和偏好编辑、三类结果、最多三个候选对比、来源详情及 JSON 导出。默认案例是虚构的；历史广告不是当前可租信息。

## 配置一次后自动读取

打开项目根目录的 `.env`，填写两行：

```dotenv
OPENAI_API_KEY=你的真实API密钥
OPENAI_MODEL=gpt-4.1-mini
```

保存后运行 `python3 server.py`。也可以使用 `nano .env` 编辑，按 Ctrl+O、回车保存，Ctrl+X 退出。修改配置后需要重启服务。`.env` 已排除在 Git 之外；`.env.example` 是不含密钥的可提交模板。

服务及 CLI 启动时读取项目目录的 `.env`，与终端当前目录无关；同名环境变量优先。配置支持空行、整行注释和一对包裹值的引号，不执行变量替换或命令。不要把密钥发到聊天或放进浏览器代码。

没有密钥仍可使用手动比较。原 `start_with_model.py` 仍可用于临时输入覆盖本地配置，但日常使用无需它。页面“模型已配置”只表示配置齐全，实际账号权限和用量仍需请求验证。

刷新页面，先在虚构数据下解析一段需求，检查条件后再点击“AI 检索与解释”。这些动作会调用模型 API 并产生用量。配置完成后只需反馈“已配置”，无需发送密钥。
